# Лад: що змінилося у вимогах v1.1

Документаційне оновлення для приватного застосунку двох рівноправних учасників, які продають кросівки через дропшипінг. Назва продукту скрізь — «Лад», не загальна назва «SNEAKERS BUSINESS».

## Головні зміни
- MVP: вхід двох учасників → оголошення → ручні рекламні платежі → продажі → простий підсумок → календар → базова PWA й безпечне розгортання.
- Одне оголошення може містити багато кольорів однієї моделі, наприклад 32 кольори Dunk. Це не 32 моделі й не окремий каталог кольорів.
- Продаж обов'язково посилається на оголошення. Опис кольору в продажі — звичайний текст, якщо він потрібний для виконання замовлення.
- Реклама належить оголошенню. Сукупна маржа завершених продажів спочатку покриває рекламні витрати; перший продаж не зобов'язаний покрити все.
- Жодного списання тієї самої реклами і в продажі, і в підсумку. Результат може бути від'ємним.
- Частки прибутку, розподіл між людьми, фактичні виплати й борги вилучені з v1. Хто заплатив за рекламу, зберігається лише як факт.
- Рейтинг, банк моделей/ідей, складна аналітика, push і інтеграція помічника — пізніше. Старі десять розділів залишаються баченням розвитку, а не умовою першого запуску.
- RLS, достовірний незмінний журнал, блокування офлайн-збережень і захист від конфліктів — до реальних даних, а не після запуску.

## Статус застосунку
Gate 1.1 додає основу Next.js (TypeScript, Tailwind, shadcn/ui) і темну українську оболонку. Бізнес-модулі, міграції БД, Auth і підключення до Supabase ще не реалізовані. Деталі — у `docs/PROGRESS.md`.

## Навігація
- START_HERE.md — як вибірково застосувати документи без автоматичного перезапису.
- docs/SPEC.md — канонічний обсяг MVP.
- docs/BUSINESS_RULES.md — формули, приклади та відкриті правила.
- docs/IMPLEMENTATION_PLAN.md — послідовність і критерії готовності.
- docs/PROGRESS.md — поточний стан і наступна дія.
- AGENTS.md — правила для агентів у цьому репозиторії.
- .gitignore.example — захист локальних файлів і секретів перед Git.

Жодних змін віддалених сервісів (Supabase/Vercel) цим етапом не зроблено.
